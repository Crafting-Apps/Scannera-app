# Scannera — website

Marketing site for [Scannera](https://play.google.com/store/apps/details?id=com.craftingapps.scannera),
a privacy-first document scanner, PDF editor and QR toolkit for Android.

Served by GitHub Pages from `/docs` on `main`.

## Local preview



```bash
python3 -m http.server 4173 --directory docs
```

Then open <http://localhost:4173>.

No build step and no dependencies beyond Google Fonts. Every page shares one
stylesheet, `docs/assets/site.css`, and one script, `docs/assets/site.js`, so a
design change happens in one place. The script only adds motion and the phone
menu; every page still reads fully with JavaScript off.

- `docs/index.html` plus four SEO landing pages, each self-contained apart
  from that stylesheet.
- `docs/assets/screenshots/` holds the fastlane store frames. These carry a
  marketing headline baked into the image, so they are used only for Open
  Graph and structured data.
- `docs/assets/ui/` holds the same screens cropped down to the app UI alone,
  generated by `youtube-assets/crop_ui.py`. The pages use the `.webp` copies
  (about a fifth of the size); re-export them whenever a PNG changes, e.g.
  `python3 -c "from PIL import Image; Image.open('x.png').save('x.webp', quality=84, method=6)"`.
  Wrap each one in `<div class="phone">` to get the device frame.
- `docs/privacy/` keeps its own inline styles and is not on the shared
  stylesheet yet.
